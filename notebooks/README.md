# notebooks/

Notebooks d'exploration et de prototypage : EDA du dataset choisi, essais rapides sur le processus de diffusion, visualisation d'échantillons générés.

Convention de nommage : `NN_sujet.ipynb` (ex. `01_eda_dataset.ipynb`, `02_diffusion_prototype.ipynb`).

Le code final et réutilisable doit être déplacé dans `src/`, pas laissé uniquement dans un notebook.
